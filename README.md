无依赖的中文静态网页。入口为 `dist/index.html`，可直接打开，或在项目目录运行 `python -m http.server 5173 --directory dist`。

- 10 个部位，92 个相关伤病及症状条目；人体热点与部位按钮均可选择。
- 当前部位内可按名称、运动场景、疼痛位置或表现查找；空结果不代表排除损伤。
- 正面 / 背面定位视角、损伤切换、局部解剖图、疼痛位置说明、表现及诱因。
- 92 个条目具有独立图稿与定位配置：76 个在图内标记关注区域，16 个明确说明目标组织未显示或痛点不固定；不将缺失结构随意标在相邻组织上。点击可放大，支持 Esc 关闭。
- 足底相关病症采用原创足底透视教学示意，籽骨炎附两枚籽骨的局部放大，跖痛症标记前掌负重区；第五跖骨骨折在足背骨图中单独突出第五跖骨。实线代表常见疼痛区域，虚线代表深部关注结构，均不代表实际病灶大小。
- 所有 92 个条目均有康复说明：27 个有分阶段基础动作，38 个提供专业指导路径，27 个先提示医疗评估。
- 动作卡可展开查看方法、器械、保守起始量、注意事项及资料来源；不按固定天数进阶。
- 响应式布局、键盘按钮、就医提示及医学参考链接。
- 不记录或上传用户健康信息。内容尚未经过临床审核，正式医疗用途前需要专业审核。

人体轮廓使用 Wikimedia Commons 公共领域资源（来源链接已在页脚列明）。图形只作区域定位，不是精确解剖模型。前后视角共用轮廓。

局部解剖图采用 InjuryMap、DBCLS、Sobotta 及公共领域插图；保留原始资源文件和解剖结构，页面通过 `dist/anatomy-zh.js` 的矢量标注层将英文改为中文，普通视图与放大图共用标注。署名、原图链接和逐图许可保存在 `dist/anatomy/credits.json`，页面注明中文标注改编。部分图为教学病变示例，不能据此判断用户的实际病灶。图上未展开的结构会另作说明。

图稿及条目匹配位于 `dist/anatomy.js`，样式位于 `dist/anatomy.css`。运行 `node check-anatomy.cjs` 检查 92 个条目的图稿覆盖、资源存在和关键解剖区域匹配。`fetch-anatomy.py` 用于重新获取已选开放许可图稿及元数据，优先复用本地缓存，并遵循维基媒体的标准预览图尺寸。

条目级标记、视图限制及原创足底示意位于 `dist/anatomy-locations.js`。标记坐标绑定具体图稿，不按身体部位自动复用。足底示意为非比例教学图；新增标记与医学插图尚需专业审核。图稿检查同时验证标记范围、底图一致性，以及籽骨炎、跖痛症、第五跖骨骨折使用不同定位。

基础内容及热点位于 `dist/app.js`；扩展条目、定位方向、就医提示和逐条来源位于 `dist/conditions.js`，运动损伤专题位于 `dist/sports-conditions.js`。`dist/style.css` 控制样式。

康复动作库、明确条目匹配和受限条目规则位于 `dist/rehab.js`。未匹配条目默认显示专业评估提示，不自动回退到同部位的普通训练。起始次数由本页保守整理，非引用资料的完整处方；内容尚未经过临床审核。

运行 `node check-rehab.cjs` 检查全量条目覆盖、动作资料完整性及骨折、断裂、急症条目不展示训练动作的规则。

网站页脚提供版权与使用说明、逐图授权和侵权反馈入口，网页位于 `dist/legal.html`、`dist/third-party-notices.html`。逐图作者和原始许可数据保持在 `dist/anatomy/credits.json`；运行 `node build-notices.cjs` 可同步生成网页和仓库授权清单。
